## 背景

[[线下品鉴马瑟兰]]的实践暴露出精准触达和第三方依赖问题，项目因此暂停。在外部交流的时候，发现人们对我的服务设计思维很感性，我转而尝试把它应用于个人生存与生活，把个人当作设计中心，构建一套能帮助自己理解、设计并运行生活环境的方法。

**本蓝图的闭环是 LessLive 仓库**：把这套方法组织为可阅读、可使用、可持续迭代的 Markdown 仓库，并免费开源。

## 我的课题

### 我喜欢

- **着迷**：把服务设计从公共服务与商业系统延伸到以个人为中心的生存与生活设计。
- **向往**：形成一套能帮助个人设计并运行自身生活环境的方法，并以 LessLive 仓库交付。
- **落差**：个人生活涉及工作、学习、健康、家庭及多种关系与资源，容易变成彼此割裂的事项；我希望用系统设计把它们组织起来。
- **主张**：剔除消耗自己的不必要，构建滋养自己的生活圈

### 我研究

- **死磕**：如何把服务设计方法用于个人生活，形成可以研究、设计、运行和迭代的个人模型。
- **付出**：持续设计 LessLive 的三大课题、蓝图与旅程结构及相关能力工具，并在自己的实践中使用和调整。
- **方法论**：以服务设计为设计方法，以人际关系作为理解和组织个人生活系统的锚点；具体历史构想保留在[[构想]]。

### 我专业

- **判断力**：个人生存与生活可以作为设计对象；服务设计方法能够被转译为个人可用的结构和工具。
- **硬手段**：将个人生活组织为不同课题，并用蓝图、旅程和能力工具承载设计与运行。
- **产品**：LessLive Markdown 仓库，提供个人生活模型及配套方法和工具。
- **承诺**：LessLive 仓库免费、开源。

## 你的课题

### 你信任

- **认可**：你看到我把服务设计用于个人生存与生活，并把形成的方法做成 LessLive 仓库，而不只是讲一套抽象理论。
- **共鸣**：当工作、学习、健康、家庭和人际关系彼此牵连，你希望有一套从自己出发、整体设计生活的方法。
- **种子**：LessLive 仓库把这套方法组织成三大课题、蓝图、旅程和能力工具；你可以从结构和我的真实实践中，看见它如何落地。

### 你选择

- **入口**：你选择免费获取 LessLive Markdown 仓库，用其中的方法和工具设计自己的个人生活模型。

### 你加入

- **你是什么样的你**：你愿意以自己为中心研究生活，并希望把设计落到真实行动中。
- **你加入的是什么**：你加入的是使用 LessLive 仓库开展个人生活设计的实践；在自己的仓库里构建、运行和迭代自己的模型，不必加入社区。
